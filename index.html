02 / SETUP

第一次設定，只要照順序做。

需求：Windows 10+、macOS 或主流 Linux、Python 3、可用的麥克風，以及约 3 GB 空間給 `qwen3:4b`。

選擇平台，安裝 Ollama

使用 Ollama 官方安裝方式。Windows 在 PowerShell 執行；macOS 與 Linux 在 Terminal 執行。

curl -fsSL https://ollama.com/install.sh | sh
ollama serve
irm https://ollama.com/install.ps1 | iex
ollama serve
curl -fsSL https://ollama.com/install.sh | sh
ollama serve

下載本機模型

模型名稱是 qwen3:4b，不是 quen3:4b。下載一次後即可重複使用。

ollama pull qwen3:4b
ollama list

下載適合你的語音助理

Windows 與 Linux 使用跨平台版；Mac 可使用跨平台版，也可選擇啟動更快、無 Whisper 依賴的 macOS 原生版。

04 / RUN

選擇模型與輸入方式，取得指令。

建議先使用每輪選擇模式；你可以在同一段對話中自由切換鍵盤與麥克風。

指令產生器

設定不會傳送到任何地方，只在瀏覽器中組合執行指令。

python3 ollama_say_zh_tw.py --model qwen3:4b --input select --rate 175

每一輪輸入 1 使用鍵盤、輸入 2 使用麥克風，輸入 q 結束。

第一次使用麥克風

在系统隱私設定中允許 Terminal、PowerShell 或「Ollama Mic Input」使用麥克風。Mac 原生版也需要語音識別權限。

說話的節奏

看到「🎤 正在聆聽」後開始說；畫面會出現 📝 即時文字。說完後按 Enter 停止。

若要暫時不朗讀，可在指令末尾加入 --no-speak。若要指定聲音，可加入 --voice "Meijia (中文（台灣）)"。
05 / FIX

常見問題，不必從頭重來。

先看錯誤訊息屬於 Ollama、模型、麥克風還是聲音，再處理對應項目。

顯示「無法連線到 Ollama」

先開啟 Ollama app，或在另一個 Terminal 視窗執行 ollama serve。接著用 ollama list 確認服務可連線。

顯示「pull model manifest: file does not exist」

檢查模型拼法。正確名稱是 qwen3:4b；常見錯誤是少打一個 w，寫成 quen3:4b。

麥克風有啟動，但沒有辨識文字

確認畫面有出現 📝 即時文字；到系統設定檢查 Terminal 或 Ollama Mic Input 的麥克風、語音識別權限，也確認「聲音 → 輸入」選中了正確裝置且輸入音量會跳動。

回答出現很長的思考內容

這個版本會忽略 Ollama 的 thinking 欄位，也會過濾 Qwen3 的 <think> 區段。請確認使用本站下載的最新 Python 主程式。

沒有中文聲音

macOS：到「輔助使用 → 朗讀內容 → 系統聲音」下載台灣中文聲音。Windows：到「時間與語言 → 語音」安裝中文語音套件。Linux 請確認 espeak-ng -v zh "你好" 可以播放。

Windows 或 Linux 麥克風缺少 Python 套件

執行 python -m pip install numpy sounddevice faster-whisper。Debian／Ubuntu 還要先安裝 libportaudio2；Linux 朗讀需要 espeak-ng。

如何清除目前的對話記憶？

在文字輸入中輸入 /clear。輸入 /quit 或在選擇畫面輸入 q 即可結束。
